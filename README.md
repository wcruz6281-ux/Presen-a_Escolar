# Presen-a_Escolar
Controle de presença escolar com reconhecimento facial opcional para registrar entradas e organizar frequências por turma e aula, com consultas, revisões e relatórios. Inclui conferência humana, auditoria e métodos alternativos, considerando possíveis erros biométricos e a proteção de dados de crianças e adolescentes[presenca_escolar_reconhecimento_facial.docx](https://github.com/user-attachments/files/33664842/presenca_escolar_reconhecimento_facial.docx)
